# 확대 지도와 도로 경로 안내

## 플레이 조작

1. `DrivingPrototype` 씬을 열고 Play한 뒤 **START!**를 누릅니다.
2. **M**을 누르면 오른쪽 아래 미니맵이 약 0.38초 동안 화면 중앙의 대형 지도로 확대됩니다. 주변 게임 화면은 살짝 어두워져 지도를 읽기 쉬워집니다.
3. 확대된 지도 위에서 **마우스 왼쪽 버튼을 누른 채 드래그**하면 다른 구역을 살펴볼 수 있습니다. 이 상태에서는 카메라 시점 회전 입력이 잠시 멈추므로 지도와 카메라가 동시에 움직이지 않습니다.
4. **M**을 다시 누르면 지도가 원래 위치와 크기로 돌아오고 카메라 마우스 입력이 다시 활성화됩니다.

청록색 선은 현재 차량 위치에서 다음 목적지까지 도로를 따라 계산한 경로입니다. 근무 시작 직후에는 물류창고로 안내하고, 소포를 적재한 뒤에는 다음 배달 지점으로 자동 갱신됩니다. 노란 화살표는 차량의 위치와 방향, 맥동하는 표시는 목적지입니다.

지도에는 `MAIN CITY`, `HARBOR CITY`, `INTERCITY EXPRESSWAY`, `RIVER VIADUCT`, `LOGISTICS`, `REST AREA`가 표시됩니다. 청록색 충전기 모양과 `EV` 표시는 실제 충전소 위치이며, 확대 상태에서 더 자세히 보입니다.

## 수정 파일과 역할

| 파일 | 역할 |
| --- | --- |
| `Scripts/Delivery/DeliveryHud.cs` | M 입력, 확대 애니메이션, 배경 페이드, 지도 드래그, 라벨·충전소·차량·목적지·경로 렌더링을 담당합니다. |
| `Scripts/World/RoadRoutePlanner.cs` | 본도시, Harbor City, 고속도로, 외곽도로와 시설 진입로를 노드 그래프로 만들고 최단 도로 경로를 계산합니다. |
| `Scripts/World/RoadMapTexture.cs` | 기본 지도 텍스처와 투명한 청록색 경로 오버레이를 생성합니다. |
| `Scripts/Camera/ChaseCamera.cs` | 확대 지도를 드래그하는 동안 카메라의 마우스 회전을 잠시 차단합니다. |
| `Tests/PlayMode/DrivingPrototypeTests.cs` | 목적지까지 경로가 생성되는지, M으로 확대·축소되는지, 카메라 입력 잠금이 함께 전환되는지 검사합니다. |

경로는 차량이 약 18m 이상 이동하거나 목적지가 바뀔 때 다시 계산합니다. 매 프레임 전체 그래프를 탐색하지 않아 HUD 갱신 비용을 줄였습니다. 현재 경로는 코드로 생성된 도로 중심선을 기준으로 하므로 실제 교통 방향, 차선 변경, 신호 대기는 아직 반영하지 않습니다.

## Unity에서 확인할 항목

- 차고에서 M을 눌러 지도가 중앙까지 부드럽게 커지고 화면 나머지가 어두워지는지 확인합니다.
- 확대 지도 안을 여러 방향으로 드래그한 뒤 M을 두 번 눌러 다시 열었을 때 차량 주변으로 돌아오는지 확인합니다.
- 물류창고로 가는 청록색 경로가 도로와 진입로 위에 놓이는지 확인합니다.
- 소포를 적재한 뒤 목적지와 청록색 경로가 다음 배달 장소로 바뀌는지 확인합니다.
- EV 아이콘 위치에서 실제 충전소를 찾을 수 있는지 확인합니다.
- Console에 빨간 오류가 없는지 확인합니다.

자동 검증은 상단 **NightCourier > Run Driving Regression Tests**에서 실행합니다. 현재 Unity 6000.6.0f1 Play 모드 회귀 테스트 **15개가 모두 통과**했습니다.
