# 전기 픽업트럭 물리 — 현재 작업 인계

## 변경 이유와 구성

- `ArcadeCarController.cs`: Rigidbody 속도·회전을 직접 덮어쓰던 방식을 없애고 4륜 WheelCollider의 motorTorque, brakeTorque, steerAngle로 이동합니다. 충돌 충격을 물리 시뮬레이션이 유지합니다. 차체 회전 고정도 제거해 서스펜션과 경사면을 따라 기울어집니다.
- 조향: 키보드 입력을 바로 바퀴에 전달하지 않고 점진적으로 반영합니다. 최대 앞바퀴 조향각은 저속 26도에서 최고속 영역 16.5도로 줄고, 조향 변화 속도도 초당 52도에서 27도로 낮아집니다. 고속에서 A/D를 눌러도 차가 갑자기 꺾이지 않으며 키를 놓으면 조금 더 빠르게 중앙으로 복귀합니다.
- 접지: 0.48m 반경 바퀴, 0.32m 서스펜션, 스프링·댐퍼·낮은 무게중심·안티롤을 적용했습니다. 좌우 마찰 stiffness를 2.1로 높이고 미끄러지기 시작하는 slip 범위를 좁혔으며, 횡방향 안정화 힘을 소폭 강화해 연속 반대 조향 때 차체가 옆으로 흐르는 양을 줄였습니다. 바퀴 외형은 GetWorldPose로 접지 높이·조향·회전을 함께 따라갑니다.
- `ElectricDriveModel.cs`: 초기 최대 구동력 14,500N, 고속 출력 제한 300kW, 속도의 제곱에 비례하는 저항과 완만한 출력 감소를 사용합니다. 65km/h 하드캡을 제거했고 평지에서 약 200km/h를 목표로 합니다. 오르막·충돌·조향에 따라 실제 속도는 달라집니다. 실제 특정 전기차의 실측 모델은 아닙니다.
- 제동: Space는 네 바퀴 제동, 반대 방향 입력은 먼저 감속 후 전진/후진 전환, 무입력은 약한 회생제동, 거의 정지한 상태는 자동 정차 유지입니다.
- `CityGeometry.cs`, `CityBuilder.cs`: 28cm 보도 턱을 60cm 길이의 경사 메시로 만들었습니다. 보도 위에서는 추가 바퀴 저항이 적용됩니다. 수직 벽·건물은 계속 충돌합니다.
- `PrototypeBootstrap.cs`: 픽업트럭 차체·캐빈·짐칸·테일게이트·큰 바퀴·휠 스포크와 택배 3개를 조립합니다. 택배는 고정된 장식이며 별도 화물 물리 시뮬레이션은 아닙니다.
- `ChaseCamera.cs`: 차체의 피치·롤을 카메라 오프셋에 그대로 전달하지 않아 서스펜션 움직임 중 화면 흔들림을 줄였습니다.
- `DrivingPrototypeTests.cs`: 새 주행 특성에 맞춘 테스트 및 보도 진입·긴 직선 고속 가속 검증을 추가했습니다. 테스트용 직선은 테스트 중에만 생성됩니다.

## Unity에서 확인

1. `DrivingPrototype`을 열고 Play를 누릅니다. Game 화면을 클릭합니다.
2. W/S 가속·후진, A/D 조향, Space 제동, R 시작 위치 복귀입니다.
3. 정지 상태에서 A/D를 눌러 앞바퀴 방향 변화를 보고, 주행 중 휠 스포크 회전을 확인합니다.
4. 낮은 속도로 보도에 비스듬히 진입해 서스펜션과 감속을 확인합니다.
5. 상단 NightCourier > Run Driving Regression Tests에서 자동 검증을 실행할 수 있습니다. 결과는 Logs/DrivingRegression.txt에 저장됩니다.

## 카메라

`C`를 누를 때마다 마우스 회전 추적 → 1인칭 → 본네트 → 왼쪽 앞바퀴 시점으로 순환합니다. 모든 시점에서 마우스 왼쪽 버튼을 누른 채 드래그해 둘러볼 수 있고, 다른 시점으로 전환하면 둘러보기 각도가 정면으로 초기화됩니다. 가속 시 3인칭은 카메라 거리가 조금 늘어납니다. 1인칭은 위치가 밀리지 않고 FOV만 최대 8도 넓어지며, 본네트와 앞바퀴 시점에는 가속 효과가 없습니다. 1인칭에서는 프로토타입 대시보드, 실시간 속도계와 실제 앞바퀴 조향값에 따라 좌우 최대 45도 회전하는 핸들이 표시됩니다.

## 차량 조명

- `Space`를 밟으면 뒤쪽의 가로형 빨간 브레이크 바가 켜집니다.
- 후진 입력 중에는 대각선 리어 램프 아래쪽의 흰 후진등이 켜집니다.
- `,`와 `.`은 각각 왼쪽·오른쪽 방향지시등을 토글합니다. 두 키를 함께 누르면 비상점멸등을 토글합니다.
- 방향지시등은 전면과 후면의 얇은 수평 램프가 같은 0.5초 주기로 점멸합니다.
- 후진등은 S 입력 자체가 아니라 실제 후진 속도에서 켜집니다. 전진 중 S를 누르면 먼저 브레이크등이 켜지고, 차가 뒤로 움직이기 시작하면 후진등으로 바뀝니다.
- 차속에 따라 저음 모터음이 높은 전기차 구동음으로 이어지는 루프를 코드에서 실시간 생성합니다.
- 배터리는 50%에서 시작하며 실제 이동거리만큼 줄어듭니다. 충전소 표시 구역에 5km/h 이하로 정차하면 자동 충전되고, 완전히 방전되면 모터 토크가 차단됩니다.
- `,`와 `.`을 짧게 함께 누르면 비상점멸등, 2초간 함께 누르면 전조등을 켜거나 끕니다. 전조등과 함께 약한 후미 주행등도 켜지고 꺼집니다.
- 적재함은 차고에서 비어 있으며 물류창고 정차 후 8개의 서로 다른 소포가 나타납니다. 배달 완료마다 한 개씩 사라집니다.

## 다음 작업

언덕과 하천 위 고가교를 포함한 약 1.2km 외곽 순환도로를 추가했습니다. 보도 위 상시 브레이크를 없애고 타이어 접지력을 강화했습니다. 최신 변경 내역과 실행법은 [도로 안내](ROADS.ko.md)를 참고하세요.

고속 급조향, 반복 벽 충돌, 다양한 보도 진입각, Windows 빌드에 대한 추가 튜닝·검증이 필요합니다. WheelCollider는 휠 중심의 ray 기반 접지이므로 임의의 높은 수직 장애물을 실제 타이어처럼 감싸 올라가지는 못합니다. 이를 위해 현재 보도의 충돌면을 경사로 모델링했습니다.
